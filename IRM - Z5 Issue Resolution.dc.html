2634.5 Cause Deep dive A. Roth · engineering

DOE on the cell B reticle stage completed for the first two legs. Overlay X-drift tracks reticle dwell time almost linearly above 40 seconds, which is consistent with reticle heating rather than a stage calibration fault. The two clean wafers in lot 24603 both ran below that dwell, so the intermittency the operators reported is explained.

Ruled out this cycle: stage calibration drift (verified against the reference plate, within 0.4 nm), chuck flatness (no correlation with field position), and the reticle swap itself (the effect reproduces on the original reticle).

Next: leg three runs in week 2638 with the compensation model enabled, on DRY 0.7 first because it carries five of the linked Z3s. If it holds, Cause closes and Solution opens with the model as the proposed fix. Blocking issue is that this Z5 has no engineering owner assigned, so nobody carries leg three.
